## How it runs

`main.py` (Python 3.13) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
and verifies its SHA-256. No network, fully deterministic — two runs write
byte-identical files.

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
